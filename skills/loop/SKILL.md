# Repetir até cumprir

Versão original escrita para o Zenith.

1. Defina a condição de parada em uma frase (por exemplo: "os testes passam").
2. Defina um limite de tentativas (padrão: 5).
3. Em cada tentativa, rode a verificação, leia a saída e ajuste só o necessário.
4. Pare quando a condição for atendida ou o limite for atingido. Informe o resultado.
