# Rodar o projeto

Versão original escrita para o Zenith (equivalente à skill "run" do Claude).

1. Procure o script de início em `package.json`, `pyproject.toml` ou no README.
2. Rode o script com `run_command` e leia a saída até o servidor ficar pronto.
3. Acesse a URL local ou execute o comando de exemplo que mostra a mudança.
4. Informe o resultado observado e qualquer erro, com a linha exata.
