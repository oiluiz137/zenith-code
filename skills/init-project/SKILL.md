# Iniciar instruções do projeto

Versão original escrita para o Zenith (equivalente ao /init).

1. Liste a estrutura de pastas com `list_dir` (até dois níveis).
2. Leia o README, `package.json` ou equivalente, e os scripts de build e teste.
3. Escreva `ZENITH.md` na raiz com: o que é o projeto, como rodar, como testar, convenções e cuidados.
4. Não invente comandos. Se não encontrar um script, escreva "não encontrado".
