# Documentos em Markdown

Versão original escrita para o Zenith.

1. Comece com título, resumo de uma frase e data.
2. Use seções curtas com títulos que dizem o conteúdo.
3. Termine com uma lista de pendências e perguntas em aberto.
4. Salve em `docs/` na pasta de trabalho.
