# Alterar configuração

Versão original escrita para o Zenith.

1. Leia o arquivo de configuração atual.
2. Mostre a mudança proposta em forma de diferença.
3. Valide o JSON antes de gravar.
4. Grave só depois de confirmação do usuário.
