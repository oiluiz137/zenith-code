# Visualização de dados

Versão original escrita para o Zenith.

1. Pergunte qual é a mensagem principal (comparar, mostrar tendência, mostrar parte do todo).
2. Escolha o tipo: barras para comparar, linhas para tendência, dispersão para relação.
3. Comece o eixo de barras em zero.
4. Use cores com contraste suficiente e não dependa só da cor para diferenciar séries.
5. Coloque título, unidade e fonte.
