# Atalhos de teclado

Versão original escrita para o Zenith.

1. Mostre a lista atual de atalhos (Ctrl+K, Ctrl+N, Ctrl+B, Ctrl+J, Ctrl+`, Ctrl+M, Ctrl+Enter).
2. Para trocar um atalho, pergunte qual ação e qual combinação.
3. Verifique conflito com atalhos do sistema operacional antes de sugerir.
4. Diga que a personalização completa ainda é planejada no 1.0.
