# Pesquisa profunda

Versão original escrita para o Zenith.

1. Escreva três a cinco perguntas que a pesquisa precisa responder.
2. Para cada pergunta, use `web_search` e depois `web_fetch` nas fontes mais confiáveis.
3. Anote a data de cada fonte. Descarte fontes sem data quando o tema for recente.
4. Compare as fontes. Se houver conflito, diga qual é mais confiável e por quê.
5. Entregue o relatório com: resumo, achados por pergunta, lista de fontes numeradas e limites da pesquisa.
