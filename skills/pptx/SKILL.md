# Apresentações (.pptx)

Versão original escrita para o Zenith.

1. Defina o número de slides e uma mensagem central para cada um.
2. Gere com `python-pptx`. Use um layout de título e um de conteúdo por slide.
3. Mantenha no máximo cinco tópicos por slide e uma ideia por slide.
4. Coloque observações para o orador em `notes_slide`.
5. Revise o texto de cada slide antes de salvar.
