# Notas Markdown

Versão original escrita para o Zenith.

1. Cada nota tem um título em H1 e um nome de arquivo igual ao título, sem acentos e com hífens.
2. Use links internos no formato `[[nome-da-nota]]`.
3. Crie uma nota de índice para cada tema.
4. Antes de criar uma nota, procure se já existe uma com o mesmo assunto.
