# Configuração inicial

Versão original escrita para o Zenith (equivalente ao guia de configuração do Claude).

1. Verifique se há um arquivo `.gguf` na pasta `models/`. Se não houver, explique como baixar um modelo como Qwen3-8B Q4_K_M.
2. Pergunte se o usuário quer um provedor de nuvem e, se sim, peça que cole a chave em Configurações.
3. Confirme a pasta de trabalho.
4. Proponha uma tarefa de teste (listar arquivos) para confirmar que tudo funciona.
