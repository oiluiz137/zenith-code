# Vídeo explicativo

Versão original escrita para o Zenith.

1. Escreva um roteiro em cinco a oito cenas, cada uma com uma ideia.
2. Para cada cena, descreva a imagem e a frase de narração.
3. Gere a narração com o provedor de voz configurado e os recursos visuais com o provedor de imagem.
4. Monte com ffmpeg, na ordem das cenas.
5. Entregue o roteiro antes de gerar qualquer mídia, para aprovação.
